How does it work?

This tool executes a deep investigation pipeline on any standard ISBN or Amazon ASIN (Kindle, Paperback, or Audio formats). It leverages our most resilient scraping fallbacks:

  • Anti-Bot Resiliency: If direct Amazon scraping is blocked by anti-bot/CAPTCHAs, it triggers search snippets, Open Library catalog queries, and Google Books API lookups.
  • Author Discovery: The scraper employs smart heuristics to isolate and match exact author names (e.g., Adrian Tchaikovsky) while ensuring book title filtering prevents name mismatch issues.
  • Automated Enrichment: Discovered authors are automatically run through the harvesting pipeline to fetch official website URLs, contact page lists, public emails, phone numbers, social media handles (YouTube, Instagram, Facebook, LinkedIn, TikTok, Goodreads), and book trailer videos.
Tip: Discovered items are immediately upserted and saved as leads in the main dashboard so you can view, score, and manage them later.
